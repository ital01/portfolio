Plataforma de Antecipação de Recebíveis Multi-Tenant (Globals)

Projeto Corporativo Integrado

Arquitetura e desenvolvimento de aplicação web corporativa em Next.js para operação financeira de antecipação de recebíveis. Estruturada em modelo multi-tenant com suporte completo a cargos e permissões (RBAC) e hierarquia complexa entre entidades do sistema (Root → Tenant → Company → Branch).

Decisões e Engenharia: Modelagem de autorização granular, isolamento rigoroso de contexto entre empresas e filiais e interface consistente.
Next.js React TypeScript Java Multi-Tenant Architecture RBAC / Permissões
