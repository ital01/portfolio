Ecossistema Mobile para Indústria Têxtil (Globals)

Produção (Android & iOS)

Desenvolvimento de dois aplicativos voltados para o setor têxtil. O primeiro consiste em uma aplicação offline-first para força de vendas de produtos têxteis via QR Code em feiras e eventos. O segundo aplicativo foca na gestão interna da empresa, englobando controle de funcionários, comissões, vendas e operações corporativas.

Decisões e Engenharia: Sincronização robusta de dados em cenários de conectividade instável (offline-first) e arquitetura modular orientada à performance em campo.
React Native Offline-First QR Code Scanning TypeScript APIs REST
