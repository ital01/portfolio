Sistema de Gestão de Navios com BFF (Globals)

Solução Corporativa

Desenvolvimento de aplicação web para gestão de navios, contando com uma camada dedicada de BFF (Backend For Frontend) construída para orquestrar e integrar de forma segura e performática com um provedor de dados externo.

Decisões e Engenharia: Abstração de contratos complexos de APIs externas na camada BFF, reduzindo o acoplamento do frontend e garantindo segurança no tráfego de dados.
BFF Pattern Node.js / NestJS TypeScript Integração Externa
